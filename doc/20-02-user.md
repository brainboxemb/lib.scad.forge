# Forge user manual

Forge is a small OpenSCAD library. Normal consumers import the umbrella API with:

```openscad
use <openscad/forge.scad>
```

Focused entrypoints under `openscad/` remain independently usable when a
consumer needs only one capability family.

## Capability areas

- semantic resolution context;
- readable transforms and coordinate frames;
- tagged body/remove/keep CSG;
- overlap-aware box/cylinder cutters.

Use native OpenSCAD directly when it expresses the intent more clearly than a
Forge helper.

## API reference

Exact signatures, arguments, examples and deprecations live in the structured
comments beside the public `.scad` source. The generated reference is build
output, not a second handwritten API authority.

## Pre-1.0 changes

Forge intentionally prefers one clear API per concept before 1.0. Deprecated
compatibility calls are temporary migration aids. Follow the replacement named
in the API comments/changelog and migrate maintained consumers during the
documented compatibility window.
